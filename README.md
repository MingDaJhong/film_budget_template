# 🎬 影片拍攝成本試算表 Film Budget Calculator

給影片拍攝者用的一頁式成本試算工具。純前端、沒有任何相依套件、不需要建置流程，打開就能算。

**線上使用：** https://mingdajhong.github.io/film_budget_template/

---

## 功能

### 📁 專案類型範本

打開「專案 / 範本」，選一個類型就套用一整份合理預算（價格為台灣市場中間帶，可再調整）：

社群短片 · 企業形象片 · 產品／電商影片 · 活動紀錄 · 音樂錄影帶 MV · 人物訪談 · 課程／教學影片 · 婚禮紀錄

套用範本只會換掉預算結構，**客戶資料、合約設定、稅務與各項加成都會保留**。

同一個面板也管理多個專案：新增、切換、複製、刪除，各自獨立存檔，不用再靠匯出／匯入換案子。換電腦時按「⬇ 匯出全部專案」，整個專案庫存成一個檔案，新機器「⬆ 匯入」一次還原。

**⇄ 並排比較**：客戶問「有沒有便宜一點的版本」時，複製一份改成精簡方案，在這裡把兩三個方案的各區塊金額、直接成本、總計與實拿並排看，最低價會自動標出來。

**🔗 產生分享連結**：把整份試算壓進網址本身傳給夥伴或客戶。**沒有經過任何伺服器** —— 資料在連結裡，不在誰的機器上。對方打開會看到一條提示，內容不會自動存進他的專案庫，要按「存成我的專案」才收下。專案太大導致連結超長時會擋下來，請改用 JSON。

### 試算區塊

| 區塊 | 內容 |
|---|---|
| 👥 人員／團隊 | 導演、攝影、燈光、收音、助理、製片。人力通常是整份預算最大的一塊，所以預設就在 |
| 🎥 器材成本 | 自訂器材名稱，可選「每天 / 每小時 / 整案」計價，搭配數量與天數（時數） |
| ✂️ 後期製作 | 剪輯、調色、字幕，以**成品分鐘**計價，自動乘上影片長度 |
| 🔁 修改／改版成本 | 設定合約內免費修改次數，超出的次數才計費（固定金額或後期費用的百分比） |
| 🚚 交通費 | 器材車、油資、停車、里程、住宿 |
| 🧾 雜費 | 餐飲、耗材、場地、保險等 |
| 📡 授權範圍加成 | 媒體 × 地域 × 年限自動換算加成，基數為拍攝＋後期費用 |
| 📦 自訂區塊 | 自己開新區塊，附「人員／團隊」「演員」「場地」「美術」「空拍」「授權」等範本，也能存自己的 |
| 📋 報價單 | 談案階段用，含有效期限、付款條件與「本報價不含」 |
| 📄 合約書 | 談成後用，一鍵產生製作合約，自動帶入總價與服務明細 |

### 計價單位

`天`、`半日`、`小時`、`加班時`、`成品分鐘`、`式（整案）`、`次`、`人`、`公里` — 每個項目都能各自切換。

- **半日**依你設定的係數計算（預設全日的 60%，業界約 4–5 小時）—— 單價欄請填**全日價**，係數會自動套上去
- **加班時**套用加班倍率（預設 1.5 倍）—— 單價欄請填**平日時薪**
- 切到這兩個單位時，欄位標題與區塊下方都會提醒該填什麼，不會算錯
- **成品分鐘**自動連動上方填的成品影片長度，改長度就整份重算

每個項目左邊的方塊是**三態**，點一下換一種：

| 狀態 | 意思 |
|---|---|
| ✓ 計入 | 算進總價，出現在報價單與合約的服務明細 |
| ＋ 選配 | **不算進總價**，報價單另列一區「選配加購」讓客戶自己勾 |
| 空白 | 完全不計入，也不會被列印出來 |

項目右邊的六點把手可以**直接拖曳調順序**，拖到哪其他列就讓開到哪；不方便拖曳時，把手 focus 後按 ↑ ↓ 也能移動。報價單與合約的明細會照著這個順序印。

### 授權範圍加成

業界的說法是「以權利計價，不是以工時計價」——同一支片只放官網、投社群廣告、上電視或買斷全媒體，價格可以差好幾倍。

選好**播放媒體 × 授權地域 × 授權年限**就會帶入建議加成（例：電視 +50%、全球 +60%、3 年 +25% = 135%），也可以直接覆寫比例。基數是拍攝與後期費用，不含交通、雜費與代墊款。

### 代墊款與實際核銷

- **代墊款**：任何區塊都能標記為代墊（例如器材外租、交通），自動加管理費（預設 12%），並在總覽裡把「代墊款」與「自有收入」分開統計 —— 分清楚才知道真正賺多少
- **趕件加成**：整案加成，跟預備金、利潤並列
- **預算 vs 實際**：打開「顯示實際欄位」，結案後填實支，即時看出結餘或超支

### ⭐ 我的常用範本

內建的範本是台灣市場中間帶的參考價，但每個人的行情不一樣。把調整好的區塊按「⭐ 存成範本」，名稱、計價單位、單價與數量就存起來，**所有專案共用** —— 下次在「新增自訂區塊」那一區一鍵帶回自己的班底與費率。實線彩框的是自己存的，灰虛線框的是內建的。

### 🎯 目標預算反推

客戶先開了預算的時候，不必一格一格試。在「金額調整與稅務」填上**目標總價**，側欄即時顯示還差多少；按「⇢ 調整到目標」就把各區塊按同一個比例縮放到剛好。

- 想保住某一塊的價格（例如已經談定的攝影師日薪），到該區塊按「🔓 鎖定金額」。鎖定後**這個區塊的單價、數量、計價單位、三態切換都改不了**，「調整到目標」也會跳過它 —— 談定的價格就該是談定的價格。項目名稱與結案用的「實際」欄位不受影響，隨時可以再按一次解鎖
- **代墊款**與**關掉的區塊**一律不動 —— 代墊是實際付出去的錢，砍不得
- 授權加成與「依後期百分比」計價的修改費是衍生值，會自己跟著調整後的金額重算
- 目標低到連鎖定的部分都蓋不住時，會直接告訴你做不到，而不是給一個錯的結果

另外，幣別下拉**只更換顯示符號、不換算金額**。要真的換匯，用「⇄ 全部金額換算」填一個倍率，所有單價、折扣、每次修改費用與實際金額都會乘上去；拿來整份調漲或打折也行。

### 🧮 稅務與實拿試算（台灣）

報價 10 萬不等於實拿 10 萬。選好接案身分就會算出「客戶付 X → 你實拿 Y」：

- **公司／工作室**：營業稅是代收代付，要繳給國稅局，不算收入
- **個人接案**：付款方先扣繳執行業務所得，單筆達門檻再扣二代健保補充保費

稅率與門檻都是可調欄位。法規會變動，實際申報請以主管機關公告或你的記帳士為準。

### 📋 報價單與 📄 合約書

兩份文件共用同一組欄位，實務順序是**先報價、談成再簽約**，預覽視窗右上角可以直接切換。

**乙方（也就是你）的資料所有專案共用** —— 名稱、統編、代表人、地址、聯絡方式，連同管轄法院、著作權歸屬、違約金、付款分期這些慣用條款，填一次就記住，開新專案自動帶入，不必每接一個案子重打一次。甲方、日期、交付項目這類每案不同的東西則各自獨立。

**報價單**含專案內容、費用明細、付款方式、期程與修改次數、本報價不含項目與客戶簽認欄，並自動附上中文大寫金額。

**合約書**是一份完整的影片製作委製契約書，試算表的結果會自動長進合約裡：

- **契約總價**帶入第四條，並自動附上中文大寫金額（如「肆萬玖仟柒佰捌拾壹元整」）
- **服務範圍明細表**由各區塊與勾選中的項目自動生成，可選擇是否顯示金額
- **修改次數條款**沿用「修改／改版成本」的免費次數與超出費用
- **付款分期**填百分比即自動換算各期金額，尾差由尾款吸收；比例不等於 100% 會提醒
- 著作權歸屬三選一、作品集展示權、保密條款、違約金比例、管轄法院都可調整
- 條號會依你開關的條款**自動重新編號**，不會出現跳號
- 未填的欄位會留下可手寫的底線，印出來就能直接簽

輸出方式：**列印／存 PDF**（自動只印合約）、**下載 Word (.doc)** 繼續編輯、**複製全文**貼到 Email 或其他文件。

> ⚠️ 產出的是合約草稿範本，用來省下打字時間，不構成法律意見。重要或高金額案件，簽署前建議請律師審閱。

### 其他

- 每個項目、每個區塊都有 checkbox / 開關，可暫時排除但不刪除，方便比較不同方案
- 側欄即時顯示各區塊佔比、直接成本、預備金／管理費、利潤、稅金、折扣與總計
- KPI：每分鐘成品成本、每拍攝日成本、拍攝期成本、後期成本
- 匯出 **CSV**（可直接開 Excel）、單一專案 **JSON**，或**整個專案庫**一次備份；匯入時自動判斷是哪一種
- 一鍵列印／存成 PDF，列印時自動隱藏按鈕與未勾選的項目
- 手機／平板上總計固定在畫面下緣，點一下升起完整總覽 —— 不用捲到最底才知道改一個數字的影響；捲到「成本總覽」時它會自動讓開，不擋內容
- 深色／淺色主題
- 多個專案各自存在瀏覽器 localStorage，**不會上傳到任何伺服器**
- 瀏覽器儲存空間滿了會把「自動儲存」轉成紅色的「存檔失敗」並說明怎麼處理，不會讓改動靜靜地掉

## 使用方式

1. 開啟 https://mingdajhong.github.io/film_budget_template/
2. 按「📁 專案 / 範本」選一個接近的專案類型套用
3. 填上方「專案基本資訊」：拍攝天數、單日工時、成品影片長度
4. 逐區塊調整單價與數量；用不到的項目取消勾選即可（人員／團隊在最上面，先把班底和日薪填對）
5. 需要新分類就用「新增自訂區塊」；外租、代墊的區塊記得標記為「代墊款」
6. 想加購但還沒確定的項目，把左邊方塊點成「＋ 選配」，報價單會另列一區給客戶勾
7. 客戶先開了預算的話，填「目標總價」按「⇢ 調整到目標」，談定的區塊記得先鎖起來
8. 右側確認總計與實拿金額，按「📋 報價單」出報價給客戶
9. 談成之後在同一個預覽視窗切到「📄 合約書」，直接出合約
10. 結案後打開「顯示實際欄位」填實支，看看這案到底賺不賺

> 換電腦時：在舊機器開「📁 專案 / 範本」按「⬇ 匯出全部專案」，新機器按「⬆ 匯入」一次讀回全部。單一個案子要傳給別人，用工具列的「⬇ JSON」。

## 檔案結構

```
index.html    頁面結構
style.css     樣式（含深／淺色主題與列印樣式）
app.js        全部邏輯（計算、繪製、存檔、報價單／合約書產生）
```

三個檔案要放在同一個資料夾。沒有建置流程、沒有相依套件，也不需要 npm。

> `app.js` 請維持外部檔案，不要 inline 回 `index.html`。Word 匯出那段字串裡有字面的 `</body>`，而 Live Server 這類開發伺服器會把熱重載用的 script 插在檔案第一個 `</body>` 之前 —— 一旦 inline，注入碼會把整段程式碼攔腰截斷。檔案開頭有詳細註解。

## 本機執行

下載後直接用瀏覽器開啟 `index.html` 即可（`file://` 也能正常運作）。

